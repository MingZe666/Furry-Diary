# 毛孩子日记 App 提案 - 初始化

## 为什么 (Why)

我们需要一款简单、离线优先且注重隐私的工具，帮助宠物主人记录宠物的健康状况。同时，为了满足现代用户对多设备无缝体验和数据安全的高要求，我们需要引入云端同步和安全的内购校验机制。目标是提供一个既能“即开即用”又能“安全云同步”的现代化宠物记录工具。

## 变更内容 (What Changes)

- **新应用开发**：使用 Flutter 开发一个完整的移动应用程序，支持 iOS 和 Android。
- **混合架构**：采用“离线优先 + 云端同步”架构。数据本地存储，有网时自动同步。
- **自研后端**：采用 Go (Golang) + MySQL 构建高性能 RESTful API，处理身份认证、数据同步和支付逻辑。
- **对象存储**：使用如 MinIO、阿里云 OSS 或自建文件服务存储图片和备份。
- **核心模块实现**：用户账户（支持手机号登录）、宠物档案、健康记录、提醒、云备份。
- **盈利策略**：实施带有服务器端校验的 免费/Pro 分层逻辑，支持微信/支付宝支付及内购。
- **UI 实现**：开发 4 个主要标签页（首页、档案、记录、我的）。

## 能力 (Capabilities)

### 新增能力
- user-auth：基于 JWT 的用户注册、登录（支持手机号验证码/邮箱）、注销及多设备与服务端会话管理。
- pet-profile：宠物信息管理（头像、名字、品种、生日、性别、毛色、芯片/护照号）。
- health-records：疫苗、驱虫、体检、用药、洗澡、体重等健康事件的记录系统。
- 
eminders：基于计划健康事件的本地通知系统。
- cloud-sync：实现“增量同步”机制，保证多端数据一致性。
- monetization：服务端处理 Apple/Google 支付回调与 Pro 权益下发。

## 影响 (Impact)

- **代码库**：
    - client: Flutter 项目。
    - server: Go + MySQL 后端项目。
- **依赖项**：
    - Flutter: dio (网络), sqflite 或 hive (本地缓存), provider/riverpod.
    - Go: gin (Web 框架), gorm (ORM), jwt-go.
- **基础设施**：
    - 云服务器 (ECS/VPS)。
    - MySQL 数据库实例。
    - 对象存储服务 (OSS/S3)。
