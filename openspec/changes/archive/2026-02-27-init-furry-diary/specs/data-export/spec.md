## 新增需求

### 需求：数据备份与导出 (Data Backup and Export)
系统必须根据用户的订阅等级提供特定的导出功能。

#### 场景：免费用户导出 PDF
- **当 (WHEN)** 免费用户尝试导出 PDF 报告（例如：疫苗本）
- **那么 (THEN)** 显示提示阻止操作
- **并且 (AND)** 重定向用户到 Pro 购买页面

#### 场景：Pro 用户导出 PDF
- **当 (WHEN)** Pro 用户请求 PDF 导出
- **那么 (THEN)** 系统生成包含所选宠物档案和健康记录摘要的 PDF
- **并且 (AND)** PDF 文件通过系统分享菜单分享

### 需求：本地数据备份 (Local Data Backup)
系统必须允许 Pro 用户在本地备份和恢复其整个数据库。

#### 场景：Pro 用户导出备份
- **当 (WHEN)** Pro 用户请求备份
- **那么 (THEN)** 系统生成包含所有数据的 JSON 或 Zip 文件
- **并且 (AND)** 文件通过系统分享菜单分享

### 需求：图片分享 (Image Share)
系统必须允许所有用户分享单个健康记录图片或卡片。

#### 场景：免费用户分享记录图片
- **当 (WHEN)** 免费用户在健康记录卡片上点击“分享”
- **那么 (THEN)** 生成该卡片的图片并通过系统分享菜单分享
