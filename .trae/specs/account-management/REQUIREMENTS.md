## 1. 功能概述

### 1.1 背景

当前项目使用编译时参数 `ACCOUNT_MODE` 区分本地模式和云端模式。本地模式下数据存储在设备本地,无法实现云端备份,存在数据丢失风险。为提升用户体验和数据安全性,需要开发账户管理功能,统一使用云端账户体系。

### 1.2 目标

- **移除本地模式**: 所有用户必须登录后使用应用
- **云端数据备份**: 数据自动实时同步到云端,防止数据丢失
- **多设备同步**: Pro用户支持多设备登录和数据同步
- **账户体系**: 支持手机号、第三方登录等多种登录方式

### 1.3 核心价值

| 价值点 | 说明 |
|--------|------|
| **数据安全** | 云端备份,防止设备丢失导致数据丢失 |
| **便捷登录** | 支持多种登录方式,降低使用门槛 |
| **多设备支持** | Pro用户可在多设备间无缝切换 |
| **实时同步** | 数据变更自动同步,无需手动操作 |

## 2. 用户故事

### 2.1 注册与登录

#### US-001: 手机号注册登录

**作为** 新用户  
**我想要** 使用手机号验证码快速注册登录  
**以便于** 快速开始使用应用

**验收标准**:
- 输入手机号后可发送验证码
- 验证码有效期5分钟
- 验证成功后自动创建账户并登录
- 首次登录引导用户设置昵称和头像

#### US-002: 第三方登录

**作为** 新用户  
**我想要** 使用微信/QQ快速登录  
**以便于** 无需输入手机号即可使用

**验收标准**:
- 支持微信、QQ第三方登录
- 首次第三方登录需绑定手机号
- 已绑定账号可直接登录

#### US-003: 账户信息设置

**作为** 已登录用户  
**我想要** 设置我的昵称、头像和邮箱  
**以便于** 个性化我的账户

**验收标准**:
- 可修改昵称(2-20字符)
- 可上传头像(支持拍照/相册)
- 可绑定/修改邮箱

### 2.2 数据同步

#### US-004: 自动数据同步

**作为** 已登录用户  
**我想要** 我的数据自动同步到云端  
**以便于** 在其他设备上也能查看

**验收标准**:
- 数据变更后自动上传到云端
- 应用启动时自动拉取最新数据
- 同步失败时提示用户

#### US-005: 多设备同步(Pro功能)

**作为** Pro用户  
**我想要** 在多个设备上登录同一账户  
**以便于** 在不同设备间无缝切换

**验收标准**:
- Pro用户可同时在多个设备登录
- 数据变更实时同步到所有设备
- 基于时间戳自动合并冲突数据

### 2.3 账户管理

#### US-006: 账户安全

**作为** 已登录用户  
**我想要** 修改我的登录方式  
**以便于** 提升账户安全性

**验收标准**:
- 可修改绑定手机号
- 可绑定/解绑第三方账号
- 可设置账户密码

#### US-007: 退出登录

**作为** 已登录用户  
**我想要** 退出当前账户  
**以便于** 切换其他账户或保护隐私

**验收标准**:
- 退出前提示数据同步状态
- 退出后清除本地敏感数据
- 下次登录需重新验证

#### US-008: 注销账户

**作为** 已登录用户  
**我想要** 注销我的账户  
**以便于** 删除所有个人数据

**验收标准**:
- 注销前需二次确认
- 注销后删除所有云端数据
- 注销后无法恢复

### 3.3 数据同步模块

#### 3.3.1 自动同步机制

**同步策略**:

| 触发时机 | 同步方向 | 说明 |
|----------|----------|------|
| 应用启动 | 下行 | 拉取云端最新数据 |
| 数据变更 | 上行 | 自动上传变更数据 |
| 定时同步 | 双向 | 每5分钟检查同步 |
| 应用切后台 | 上行 | 上传未同步数据 |

**同步流程**:

```
┌─────────────┐
│  数据变更   │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 标记为脏数据 │
└──────┬──────┘
       │
       ▼
┌─────────────┐    ┌─────────────┐
│  网络可用?   │──否──▶│ 加入同步队列 │
└──────┬──────┘    └─────────────┘
       │是
       ▼
┌─────────────┐
│  上传数据   │
└──────┬──────┘
       │
       ▼
┌─────────────┐    ┌─────────────┐
│  上传成功?   │──否──▶│ 重试机制   │
└──────┬──────┘    └─────────────┘
       │是
       ▼
┌─────────────┐
│ 标记为已同步 │
└─────────────┘
```

#### 3.3.2 冲突处理策略

**基于时间戳的自动合并**:

1. **字段级冲突**: 每个字段独立比较 `updated_at` 时间戳
2. **记录级冲突**: 整条记录比较 `updated_at` 时间戳
3. **删除冲突**: 删除操作优先级最高

**冲突场景示例**:

| 场景 | 设备A | 设备B | 解决方案 |
|------|-------|-------|----------|
| 同字段修改 | 修改昵称为"小白"(10:00) | 修改昵称为"小黑"(10:01) | 采用"小黑" |
| 并发修改 | 添加记录R1(10:00) | 添加记录R2(10:00) | 两条记录都保留 |
| 删除与修改 | 删除记录R1(10:01) | 修改记录R1(10:00) | 记录R1被删除 |

#### 3.3.3 多设备登录限制

**免费用户**: 单设备登录
- 新设备登录时,旧设备被挤下线
- 旧设备收到"账号在另一设备登录"提示
- 需重新登录才能继续使用

**Pro用户**: 多设备登录
- 支持同时在最多3个设备登录
- 超过限制时,最早登录的设备被挤下线
- 数据实时同步到所有在线设备

### 3.4 网络状态处理

#### 3.4.1 网络检测

**必须联网使用**:
- 应用启动时检测网络状态
- 无网络时显示"网络不可用"提示页
- 提示用户检查网络连接
- 提供"重试"按钮

**网络状态监听**:
- 实时监听网络变化
- 网络恢复后自动同步数据
- 同步状态显示在状态栏

#### 3.4.2 网络异常处理

| 异常场景 | 用户提示 | 处理方式 |
|----------|----------|----------|
| 无网络连接 | "网络不可用,请检查网络设置" | 显示网络错误页 |
| 请求超时 | "网络连接超时,请稍后重试" | 自动重试3次 |
| 服务器错误 | "服务器繁忙,请稍后重试" | 延迟重试 |
| Token过期 | "登录已过期,请重新登录" | 跳转登录页 |
| 弱网环境 | "当前网络较差,数据同步中..." | 显示同步中状态,降低同步频率 |
| 频繁切换网络 | "网络不稳定,请稍后重试" | 暂停同步,等待网络稳定 |
| 请求失败 | "操作失败,请稍后重试" | 加入失败队列,支持手动重试 |

#### 3.4.3 边界场景处理

**弱网环境优化**:
- 检测网络质量 (延迟、丢包率)
- 弱网时自动降低图片质量
- 减少非必要请求
- 显示"正在同步"提示,避免用户重复操作

**断网续传**:
- 网络中断时,将待上传数据持久化到本地
- 网络恢复后,自动继续上传
- 支持断点续传,避免重复上传

**数据一致性保证**:
- 使用事务保证本地数据原子性
- 云端数据采用乐观锁机制
- 同步失败时回滚本地变更

| 指标 | 要求 |

    var req struct {
        Code string `json:"code" binding:"required"`
    }
    
    // 1. 使用code换取access_token和openid
    token, err := wechat.GetAccessToken(req.Code)
    
    // 2. 查询或创建用户

    jwtToken := h.generateJWT(user.ID)

}

    }
    
    // 1. 验证access_token

    // 2. 查询或创建用户

}

## 9. 安全考虑

### 9.1 认证安全

| 安全措施 | 实现方式 |
|----------|----------|
| JWT Token | 有效期7天,存储在 flutter_secure_storage |
| Token刷新 | Token过期前1天自动刷新 |
| 设备绑定 | Token中包含设备ID,防止Token被盗用 |
| 登录日志 | 记录登录时间、IP、设备信息 |

### 9.2 数据安全

| 安全措施 | 实现方式 |
|----------|----------|
| HTTPS | 所有API请求强制HTTPS |
| 数据加密 | 敏感字段(手机号、邮箱)加密存储 |
| 数据脱敏 | API响应中手机号、邮箱脱敏显示 |
| 软删除 | 用户数据采用软删除,支持恢复 |

### 9.3 第三方登录安全

| 安全措施 | 实现方式 |
|----------|----------|
| State参数 | 防止CSRF攻击 |
| 回调验证 | 验证回调URL合法性 |
| Token验证 | 验证第三方access_token有效性 |
| OpenID绑定 | 一个OpenID只能绑定一个账户 |

### 9.4 验证码安全

| 安全措施 | 实现方式 |
|----------|----------|
| 频率限制 | 同一手机号每天最多发送5次 |
| 有效期 | 验证码有效期5分钟 |
| 错误限制 | 连续错误3次,锁定15分钟 |
| 验证后失效 | 验证成功后立即失效 |

### 9.5 安全监控与审计

**安全监控**:
| 监控项 | 说明 | 响应措施 |
|--------|------|----------|
| 异常登录 | 异地登录、频繁失败 | 发送通知、验证码确认 |
| 验证码滥用 | 发送频率异常 | 临时封禁 IP |
| 批量注册 | 短时间内大量注册 | 人工审核 |
| API 攻击 | 请求频率异常 | 限流、封禁 |

**审计日志**:
| 日志类型 | 保留时间 | 记录内容 |
|----------|----------|----------|
| 登录日志 | 1年 | 时间、IP、设备、结果 |
| 操作日志 | 1年 | 用户 ID、操作类型、变更内容 |
| 管理日志 | 3年 | 管理员操作、权限变更 |
